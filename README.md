1. Extract the project folder.
2. Open `index.html` in a modern browser.
3. Use the dashboard cards to open HTML, CSS, or JavaScript program lists.
4. Open any individual experiment to run its demonstration.
5. Use the Home / Back to Programs navigation on each page.
